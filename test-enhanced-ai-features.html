🧪 Feature Testing Guide

🎤 Voice Features Test

To test voice recognition:

  1. Click the "Voice Input" button in the AI Assistant header
  2. Say: "Check train 12307 status"
  3. The system should auto-detect the train number and fetch information
  4. Try: "Tell me about platform information"

To test text-to-speech:

  1. Click "Voice Demo" button to hear AI introduction
  2. Send a chat message and listen for AI response
  3. Use voice input - responses will be spoken automatically

🚨 Popup Notifications Test

To test popup notifications:

  1. Enter train number 12307 and get AI guidance
  2. Wait 30 seconds for automatic notification check
  3. Urgent notifications will appear as popup in top-right corner
  4. Browser notifications will also appear (if permission granted)
